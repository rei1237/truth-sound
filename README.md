# Truth Sound

[브라우저 녹음 작업실 열기](https://rei1237.github.io/truth-sound/)

웹판은 녹음을 열면 **강화 보정**을 자동 실행합니다. 파형 위 **전체 보정**에서 기본/강화를 비교하고 **강화 보정 WAV 저장**으로 전체 음성을 내려받으세요. 강화 모드는 주변 소음을 추정해 줄이고, 발음 대역을 조정하며, 짧은 구간별 음량 제어와 소프트 리미터로 작은 소리를 더 크게 만듭니다. 결과는 원본과 길이가 같은 16kHz 모노 WAV입니다. 훼손된 발음의 복원이나 인식 정확도를 보장하지 않으며 중요한 문구는 원본과 대조해야 합니다. 전체 녹취에는 선택한 보정본이 사용되고, 보정 방식을 바꿔도 기존 녹취의 보정본 및 처리 기록은 유지됩니다.

공개 웹판의 PC 편집기 화면에 녹음을 끌어다 놓으면 원본과 전체 보정본 파형이 왼쪽에, 녹취록이 오른쪽에 열립니다. 상단 **녹취록 만들기**로 두 음성을 각각 인식하고 화자 번호를 추정합니다. 특정 구간만 비교하려면 파형을 드래그한 뒤 **선택 구간만 녹취**를 누르세요. 후보가 다르면 해당 줄에서 두 음성을 듣고 직접 고를 수 있습니다. **구간 분석 → 전체 보정본 듣기 · WAV 저장**에서 보정본을 저장하고, **내보내기**에서 검수 문서와 처리 기록을 받으세요. 녹음과 초안은 탭 안에서 처리하며 처음 실행할 때 AI 모델을 내려받습니다.

짧거나 모호한 발화는 ‘화자 미상’으로 두고 직접 지정하세요. 특히 어려운 대목은 30초 이하의 범위에서 **선택 구간만 녹취**로 후보를 추가할 수 있습니다. **원본 구간 듣기**로 대조하고 화자와 문구를 검수한 뒤, 탭을 닫기 전에 저장하세요. **제출 자료 ZIP 저장**은 녹취록 DOCX와 처리 기록 JSON을 같은 검수 상태로 묶습니다. 처리 기록에는 원본·전체 보정 WAV의 SHA-256, 보정 방법, 발화별 입력 및 수정 이력이 남습니다. 화자별 오디오 트랙 분리와 사건 보관은 아래 Windows PC판에서 제공합니다.

통화 녹음 파일에서 **나 / 통화 상대방 / 상대방 옆 사람**의 목소리를 사람별로 나누고,
작게 들리는 목소리를 키운 청취 보조용 음성과 녹취록 초안을 만드는 PC 프로그램입니다.
증거 제출과 녹취록 작성을 돕기 위해 만들었습니다.

모든 처리는 이 PC 안에서만 합니다. 녹음은 인터넷으로 보내지 않습니다.
(처음 설치할 때와 첫 처리 때 AI 모델을 내려받을 때만 인터넷을 씁니다.)

> **주의** 이 녹취록은 Truth Sound가 AI로 받아쓴 초안을 바탕으로 작성되었습니다.
> 정확한 내용은 원본 녹음 파일을 직접 들어 확인해야 합니다.
> 함께 제공되는 분리·보정 음성은 청취 보조용이며 원본이 아닙니다.

## 작은 소리와 불확실한 녹취

새 녹음을 확인한 뒤 **녹취록 작성 시작**을 누르면 샘플 없이 원본 받아쓰기가 시작됩니다. 기존 사건은 **녹취록 만들기**로 다시 처리할 수 있습니다. 이전 녹취록은 사건의 work 폴더에 보관됩니다.

첫 받아쓰기에서 빠진 소리는 해당 구간만 최대 30dB 키워 다시 인식합니다. 두 번째 인식 결과와 자막·잡음으로 의심되는 문구는 **불확실 · 원본 확인 필요**로 초안에 남습니다. 소리는 있지만 글을 얻지 못한 후보는 **[판독 불가]**로 표시합니다. 구간 분석 탭에서 원본 트랙의 30초 이하 구간을 선택하고 **청취 보조**에서 **보정 전**, **작은 소리 확대**, **잡음 줄이고 말소리 듣기**를 바꿔 같은 구간을 들을 수 있습니다. 마지막 방식은 앞뒤 최대 0.5초를 참고해 일정한 배경 잡음을 줄이고, 저음 진동을 낮추며 자음 대역을 살립니다. 약한 자음도 함께 줄어들 수 있으므로 중요한 단어는 보정 전 소리와 대조하세요. 보정본은 청취용이며 녹취록 내용이나 원본 파일은 바뀌지 않습니다.

제출 자료를 준비할 때는 원본 파일, SHA-256이 적힌 처리 기록(JSON, 불확실한 줄의 원본 시작·끝 시각과 검수 여부 포함), 검수한 녹취록(DOCX 또는 TXT)을 함께 보관하세요. 짧거나 겹친 말에서 화자와 문구를 구분하기 어려우면 그 상태를 녹취록에 남겨 주세요.

## 필요한 것

- Windows 10 또는 11 (64비트)
- NVIDIA 그래픽카드(그래픽 메모리 8GB 권장). 없으면 CPU로 처리하며 훨씬 느립니다.
- 메모리 16GB 이상
- 디스크 빈 공간 약 15GB (프로그램 약 5GB, 설치용 내려받기 임시 파일 약 3GB, AI 모델 약 3.5GB, 사건마다 녹음 길이에 따라 추가)

## 처음 설치

1. **uv 설치**: 시작 메뉴에서 PowerShell을 열고 아래 명령을 붙여 넣습니다.

   ```
   powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
   ```

2. 이 폴더의 **`TruthSound.bat`을 더블클릭**합니다.
   처음에는 필요한 프로그램을 설치하느라 몇 분에서 수십 분 걸립니다.
3. 설치가 끝나면 브라우저에 Truth Sound 화면이 열립니다.

다음부터는 `TruthSound.bat`만 더블클릭하면 됩니다. 검은 창을 닫으면 프로그램이 꺼집니다.
이미 켜져 있을 때 다시 더블클릭하면 화면만 새로 열립니다.

## 쓰는 법

화면은 소리 편집 프로그램(Audacity)처럼 위에서 아래로 도구 줄 · 눈금자 · 트랙들이 있고, 오른쪽에 [구간 분석] [녹취록] [샘플] 탭이 있습니다.
순서는 **녹음 넣기 → 확인 카드 → 편집 화면에서 샘플 지정 → [화자 분리] → [녹취록] 탭에서 검수 → [내보내기]** 입니다.

1. **녹음 넣기**: 빈 화면에 통화 녹음 파일(m4a, mp3, amr, wav, ogg 등)을 끌어다 놓거나 [파일 고르기]를 누릅니다.
   프로그램이 원본을 그대로 복사해 읽기 전용으로 보관하고 SHA-256 값을 기록합니다.
   편집 화면 맨 위에 그 값(봉인 표시)이 늘 보입니다. 아래쪽 "최근 녹음"에서 예전 사건을 다시 열 수 있습니다.
2. **확인 카드**: 놓은 뒤 파일 이름, 작은 파형과 ▶ 듣기, 길이, 형식, 지문(SHA-256)이 카드로 나옵니다.
   - 소리가 잘린 곳이 1% 이상이면 경고가 나옵니다. 증폭하기 전 원본이 있으면 그 파일을 쓰세요.
   - 이미 연 적이 있는 녹음이면 알려 줍니다. [그 녹음 열기] 또는 [새로 계속]을 고르세요.
   - 맞으면 [녹취록 작성 시작], 잘못 골랐으면 [다른 파일]을 누릅니다.
3. **샘플 지정**: 편집 화면의 트랙에서 **그 사람 혼자 또렷하게 말하는 곳**을 마우스로 끌어 고른 뒤,
   선택 위에 뜨는 [샘플로 지정 ▾]에서 사람을 고르거나 숫자키 **1·2·3**(첫째·둘째·셋째 사람)을 누릅니다.
   - '목소리 샘플' 줄에 사람 색 조각으로 나타납니다. 조각 가장자리를 끌어 늘이고 줄이며, 조각을 누르고 Delete로 지웁니다.
   - '네' 한마디(0.2초 이상)처럼 아주 짧아도 처리합니다. 다만 짧을수록 사람이 뒤바뀌어 배정될 수 있어,
     가능하면 사람마다 모두 합쳐 2초 이상, 5~10초를 권장합니다.
   - 구간을 지정한 사람만 처리합니다. 2명 또는 3명이어야 합니다.
     (옆 사람이 없는 통화라면 나와 상대방만 지정하세요.)
   - 다른 사람의 샘플과 겹치는 곳은 지정할 수 없습니다. 잘린 소리가 섞인 곳을 지정하면 한 번 확인을 묻습니다.
   - [샘플] 탭에서 이름 칸에 실제 이름을 적으면 녹취록에도 그 이름으로 나옵니다. 구간 목록에서 ▶ 듣기·✕ 지우기도 됩니다.
4. **[화자 분리]**: 도구 줄의 [화자 분리](처리한 뒤에는 [다시 처리])를 누르고 확인 말풍선에서 [시작]을 고릅니다.
   목소리 분리 → 음성 보정 → 받아쓰기 순서로 진행되고, 진행 상황이 도구 줄 아래 띠에 보입니다.
   첫 처리 때는 AI 모델(약 3.5GB)을 내려받습니다. 긴 녹음은 수십 분 걸릴 수 있습니다. 처리 중에는 샘플을 바꿀 수 없습니다.
   - 녹음을 0.2초 간격으로 0.6초씩 살펴 그때 말하는 사람을 정합니다. 그래서 '네' 같은 아주 짧은 말도
     따로 배정됩니다. 목소리 샘플로 지정한 곳은 그 사람으로 고정합니다.
   - 0.2~0.3초짜리 '네'·'응'처럼 너무 짧아 누구인지 못 알아본 소리는 같은 녹음에서 사람마다 배운
     음색(10ms 단위)과 다시 비교합니다. 한 사람과 뚜렷이 닮았을 때만 그 사람에게 주고, 샘플 없는
     사람이 길게 말한 목소리와 닮았거나 애매하면 "화자 확인 필요"로 둡니다. 이렇게 정한 줄은 검수에서 따로 표시됩니다.
     (사람마다 그 녹음에서 판정된 말소리가 0.15초 이상 있어야 이 비교를 합니다. 0.4초 샘플이면 됩니다.)
   - **증폭한 파일은 넣지 마세요.** 너무 키워 저장하면 소리 꼭대기가 잘려 음색이 바뀌고, 화자 판정이 틀리기 쉽습니다.
     잘린 소리가 많으면 처리 뒤 "녹음의 13%가 너무 커서 잘린 소리입니다"·"상대방: 목소리 샘플의 72%가 잘린 소리…"처럼
     알려 줍니다. 작은 목소리는 Truth Sound가 알아서 키우니 증폭하기 전 원래 녹음을 등록하세요.
   - 끝나면 "샘플 밖에서 찾은 말: 나 12.4초 · 상대방 8.0초 …"처럼 사람마다 샘플 말고 더 찾은 시간이 나옵니다.
     사람별 트랙(나·상대방·옆 사람)과 녹취록 줄이 편집 화면에 생기고 [녹취록] 탭이 열립니다.
   - **목소리 샘플이 없을 때는 [녹취록 만들기]**: [화자 분리] 옆의 [녹취록 만들기]는 샘플을 지정하지 않아도 누를 수 있습니다.
     원본 녹음에서 바로 받아쓰기만 하므로 사람별 트랙은 생기지 않고, 모든 줄의 화자는 "화자 확인 필요"로 나옵니다.
     [녹취록] 탭에서 원본을 들으며 화자를 직접 고르세요. 이 한계를 알고 쓰세요.
     - 두 사람이 겹쳐 말한 곳은 화자 분리를 했을 때보다 더 틀리거나 빠질 수 있습니다.
     - 줄마다 [▶분리 음성]은 쓸 수 없고 [▶원본]만 듣습니다.
     - 처음 한 번은 받아쓰기 모델(약 3GB)을 내려받습니다. 이미 받았다면 받지 않습니다.
     - 이미 녹취록이 있으면 지금 녹취록과 고친 내용이 새 결과로 바뀝니다. 이전 녹취록은 따로 보관됩니다.
     - 이미 나눈 사람별 트랙이 있으면 그대로 둡니다.
5. **[녹취록] 탭에서 검수**: 녹취록을 한 줄씩 확인합니다. 줄을 누르면 트랙에서 그 구간이 선택됩니다.
   - ▶원본으로 그 줄의 원본 소리를, ▶분리 음성으로 그 사람만 나눈 소리를 듣습니다.
   - 글을 눌러 고치고(Esc 또는 Ctrl+Enter로 끝), 화자가 틀렸으면 고릅니다. 고친 내용은 자동으로 저장됩니다.
   - <mark>노란 표시</mark>는 AI가 자신 없는 단어입니다. 특히 잘 들어 보세요.
   - 확인이 끝난 줄은 "검수" 칸을 체크합니다. "검수 안 한 줄만"으로 남은 줄만 볼 수 있습니다.
   - 다른 사람 말이 새어 들었거나 잡음을 받아쓴 줄은 글 아래 칸에서 "빼기"와 이유를 고릅니다.
     문서에서는 빠지고, 처리 기록(JSON)에는 뺀 줄과 이유가 남습니다.
   - "중복 의심"·"자동으로 뺌: 중복 의심" 표시는 같은 시각 다른 사람 줄과 같은 말이라는 뜻입니다. 원본으로 누구 말인지 확인하세요.
   - 이전 버전의 "자동으로 뺌: 지어낸 말 의심"은 받아쓰기 모델이 말이 없다고 본 짧은 틈에 말할 수 없을 만큼 글자가 많이 나온 줄입니다
     (예: "영상편집 및 자료조사 …" 같은 자막 문구). 지우지 않고 문서에서만 빼 두었으니, 원본을 듣고 실제로 한 말이면 "문서에 넣기"를 고르세요.
   - AI가 놓친 말은 원본을 그 위치까지 재생하거나 구간을 고른 뒤 "＋ 줄 넣기"를 눌러 직접 적습니다.
   - 화자 칸이 주황색인 **"화자 확인 필요"** 줄은 어느 목소리 샘플과도 뚜렷이 닮지 않은 소리입니다.
     "화자 확인 필요 N줄"을 누르면 그 줄만 모아 봅니다. 원본을 듣고 화자를 고르거나 "빼기"를 고르세요.
     그대로 두면 문서에는 **"화자 미상"**으로 나옵니다.
   - **"짧은 소리: 화자 추정"** 표시는 아주 짧은 소리라 목소리 특징만으로는 확실하지 않아, 음색이 가장 닮은
     사람으로 정한 말이 든 줄입니다. 원본을 듣고 맞으면 검수 체크, 아니면 화자를 고르세요.
     검수 전에는 문서에 이름 뒤 **(추정)**이 붙고, "주의"에 그 뜻과 남은 줄 수가 적힙니다.
     트랙의 녹취록 줄에서도 빗금과 "(추정)"으로 다르게 보입니다.
6. **[내보내기]**: 윗줄의 [내보내기]를 누르고 "녹취록 문서 만들기"를 누르면 아래 파일을 내려받을 수 있습니다.
   - 녹취록 Word 문서(DOCX)와 텍스트(TXT)
   - 처리 기록(JSON): 원본 정보, 사용한 모델과 설정, 처리·검수·내보내기 기록. 윗줄의 [처리 기록]에서는 화면으로도 볼 수 있습니다.
   - 사람별 분리 음성(WAV, 16kHz). "화자 확인 필요" 소리가 있었다면 `청취보조_화자확인필요.wav`도 함께 나옵니다.

### 편집 화면 조작

마우스
- 끌기 = 구간 선택, 클릭 = 재생 위치 옮기기.
- 휠 = 위아래 스크롤, Shift+휠 = 좌우 이동, Ctrl+휠 = 마우스 위치를 기준으로 확대·축소.
- 아래 상태 줄의 시작·끝·길이 칸에 시각(`00:00:05.050`)을 직접 써서 선택을 바꿀 수 있습니다.

키 (한글 입력 상태에서도 됩니다. 글을 쓰는 칸에서는 반응하지 않습니다)

| 키 | 하는 일 |
|---|---|
| Space | 재생/멈춤 (선택이 있으면 선택 구간) |
| Home / End | 처음 / 끝으로 |
| L | 반복 켜고 끄기 |
| [ / ] | 이전 / 다음 말소리로 가서 선택 |
| = / - | 확대 / 축소 |
| F | 전체 보기 |
| E | 선택 구간에 맞춰 확대 |
| 1 / 2 / 3 | 선택을 첫째·둘째·셋째 사람 샘플로 지정 |
| Delete / Backspace | 고른 샘플 조각이 있으면 그 조각을 지우고, 아니면 타임라인 선택 구간을 비파괴 방식으로 잘라내기 |
| Ctrl+Z / Ctrl+Y | 마지막 컷 되돌리기 / 다시 적용 |
| Esc | 선택 풀기, 열린 말풍선 닫기 |

컷 편집은 원본 파일을 바꾸지 않습니다. 잘라낸 구간은 사건의 편집 기록에 원본 시각으로 저장되며,
도구 줄의 ↶·↷ 또는 Ctrl+Z·Ctrl+Y로 여러 단계 되돌리기와 다시 적용을 할 수 있습니다.
컷이 녹취록 줄 일부와 겹치면 그 줄은 "컷 이후 재검수 필요"로 표시됩니다.

처음에는 **원본만 소리가 나고** 나머지 트랙은 꺼져 있습니다. 트랙 왼쪽 [끄기]·[단독]으로 소리를 켜고 끕니다.
도구 줄에서 1× · 0.75× · 0.5× · 0.25× 속도로 목소리 높이는 그대로 느리게 들을 수 있습니다.

### 분석 기능 여섯 가지

분석은 **보는 도구**입니다. 결과는 화면에만 보이고 사건 파일·녹취록·내보낸 문서에는 들어가지 않습니다.
**닮음 점수·분석 수치는 참고용이며 판정·문서에 들어가지 않습니다.**

1. **주파수 그림**: 트랙마다 [파형↔주파수]로 바꿔, 소리의 높낮이별 세기를 색으로 봅니다.
2. **구간 분석**: 구간을 고르면 [구간 분석] 탭에 길이, 최고·평균 소리 크기(dB), 잘린 소리 비율, 목소리 높이, 주파수 분포, 말소리 비율이 나옵니다.
   [닮음 점수 보기]를 누르면 사람별 샘플과 목소리가 얼마나 닮았는지 참고로 보여 줍니다(처리 중에는 쓸 수 없습니다).
3. **느리게·반복 듣기**: 0.75×·0.5×·0.25×로 목소리 높이를 지키며 느리게 듣고, L로 고른 구간을 되풀이해 듣습니다.
4. **잘린 소리 빨간 표시**: 소리가 너무 커서 잘린 곳을 파형 위에 빨간 줄로 칠합니다.
5. **목소리 높이 선**: 주파수 그림 위에 목소리 기본 높이를 선으로 겹쳐 보여 줍니다(60초 이하로 확대했을 때).
6. **말소리 위치 띠**: 눈금자 아래 띠에 말소리가 있는 곳을 칠하고, [ ]로 이전·다음 말소리로 건너뜁니다.

## 증거로 쓸 때 알아 둘 것

- **원본은 바뀌지 않습니다.** 원본 사본은 읽기 전용으로 보관하고, 처리할 때와 내보낼 때마다
  SHA-256 값을 다시 계산해 등록 때와 비교합니다. 다르면 화면과 문서에 빨간 경고가 나옵니다.
- **분리 음성은 청취 보조용이며 원본이 아닙니다.** 파일 이름이 `청취보조_<이름>.wav`이고,
  파일 정보에도 "청취 보조용 - 원본 아님"이 적혀 있습니다.
  한 사람이 혼자 말한 구간은 원본 소리를 그대로(16kHz로만 바꿔) 옮기고, 둘 이상이 동시에 말한 구간만
  AI로 나눈 소리를 씁니다. 그 뒤 작은 소리를 키우는 보정을 합니다.
  없는 소리를 만들어 낼 수 있는 AI 음질 복원(대역 확장)은 쓰지 않습니다.
- **녹취록은 AI 초안입니다.** 모든 줄을 원본으로 듣고 검수 체크를 하고, 내용이 빈 줄이 없어야 문서 제목이
  "녹취록 (초안)"에서 "녹취록"으로 바뀝니다. 검수하지 않은 줄의 자신 없는 단어 뒤에는 (?)가 붙고,
  짧은 소리라 화자를 추정한 줄은 이름 뒤에 (추정)이 붙습니다.
- 제출할 때는 **처음 받은 원본 녹음 파일**을 함께 내세요.
- 옆 사람 발언을 증거로 쓸 수 있는지 등 법률 판단은 변호사와 확인하세요.

## 파일이 저장되는 곳

프로그램 폴더 안 `data\cases\<사건 번호>\`에 사건마다 따로 저장됩니다.

| 폴더·파일 | 내용 |
|---|---|
| `original\` | 원본 사본(읽기 전용) |
| `tracks\` | 사람별 분리 음성(청취 보조용) |
| `exports\` | 내보낸 녹취록과 처리 기록 |
| `case.json` | 원본 정보·목소리 구간·처리 기록 |
| `transcript.json` | 검수 중인 녹취록 |

AI 모델은 `models\`에 있습니다. 다른 곳에 저장하려면 환경 변수 `TRUTHSOUND_HOME`에 폴더를 지정하세요.

## 잘 안 될 때

- **"메모리가 부족합니다"**: 안드로이드 에뮬레이터(LDPlayer 등), 게임, 브라우저 탭 여러 개처럼
  메모리를 많이 쓰는 프로그램을 닫고 다시 처리하세요. 그래픽 메모리가 모자라면 자동으로
  가벼운 방식 → CPU 순서로 바꿔 계속하지만, 그만큼 느려집니다.
- **사람이 잘못 나뉨**: 목소리 샘플을 더 길게(5~10초), 다른 사람 말이 섞이지 않은 곳으로 다시 지정하고
  "다시 처리"하세요. 이전 녹취록은 따로 보관됩니다. 몇 줄만 틀렸다면 [녹취록] 탭에서 화자를 고치면 됩니다.
- **옆 사람 목소리가 너무 작음**: 그 사람 목소리가 들리는 곳을 찾아 지정하세요(짧아도 되지만 길수록 정확합니다).
  분리 음성에서는 크게 키워서 들려줍니다.
- **"목소리 샘플로 지정한 곳 말고는 이 사람으로 판정된 구간이 없습니다"**: 그 사람 샘플이 너무 짧거나
  다른 사람 말이 섞였을 수 있습니다. 그 사람 혼자 말하는 곳을 더 길게 지정해 다시 처리하세요.
- **"화자를 확인하지 못한 구간이 N%입니다"**: 말소리의 30% 이상이 누구와도 뚜렷이 닮지 않았다는 뜻입니다.
  목소리 샘플을 사람마다 2초 이상 지정하면 줄어듭니다. 샘플을 지정하지 않은 사람이 말하는 경우에도 나옵니다.
- **소리가 깨진 녹음**: 소리를 크게 키워 저장한 파일은 큰 소리가 잘려(찌그러져) 목소리 구분과 받아쓰기가
  모두 나빠집니다. 키우지 않은 **처음 녹음 파일**을 넣으세요. 작은 소리는 프로그램이 알아서 키웁니다.
- **화면이 안 열림**: 검은 창에 나온 주소(`http://127.0.0.1:8765/`)를 브라우저에 직접 입력하세요.

## 시험용 가짜 통화

Windows 한국어 음성(Heami)으로 3명이 말하는 가짜 통화를 만들 수 있습니다.

```
uv run python scripts/make_demo_call.py
```

`data\demo\가짜통화_3인.wav`가 생기고, 사람마다 혼자 말하는 구간이 화면에 나옵니다.

## 개발자용

- 테스트: `uv run pytest -q`
- 실제 AI 모델 테스트(내려받기·GPU 필요): PowerShell에서
  `$env:TRUTHSOUND_MODEL_TESTS="1"; uv run pytest -q tests/test_models_smoke.py`
- 구성: `truth_sound/`에 사건 보관(`case_store.py`), 음성 보정(`dsp.py`), 분리(`separate.py`),
  받아쓰기(`transcribe.py`), 전체 흐름(`pipeline.py`), 내보내기(`export.py`), 로컬 서버(`server.py`),
  화면(`static/`)이 있습니다.
- 사용한 AI 모델: speechbrain `sepformer-whamr`(2명), `sepformer-wsj03mix`(3명),
  `spkrec-ecapa-voxceleb`(목소리 대조), faster-whisper `large-v3`(받아쓰기).
- 글꼴: Pretendard (SIL OFL 1.1, `truth_sound/static/fonts/`).
